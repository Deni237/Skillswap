# SkillSwap — Documentation Complète

## 1. Introduction
SkillSwap est une application mobile Android permettant aux utilisateurs d’échanger des compétences, d’apprendre et de proposer leurs services. Développée en Kotlin avec Jetpack Compose, elle suit une architecture moderne (MVVM + Navigation Compose).

## 2. Fonctionnalités
- Authentification
- Profil utilisateur
- Catalogue des compétences
- Messagerie
- Favoris
- Notifications
- Paramètres du compte


## 4. Structure du projet
```
Skillswap/
│── app/

```

## 5. Installation
```
git clone https://github.com/Deni237/Skillswap.git
cd Skillswap
```
Ouvrir dans Android Studio → Run.

## 6. Tutorial d’utilisation
### Étape 1 : Ouvrir l’application
Arrivée sur l’écran d’accueil (Dashboard).

### Étape 2 : Naviguer entre les onglets
- Accueil
- Messages
- Favoris
- Notifications
- Profil

### Étape 3 : Voir ou proposer une compétence
Cliquer sur une carte → détails de la compétence.

### Étape 4 : Modifier son profil
Onglet Compte → Modifier informations.
